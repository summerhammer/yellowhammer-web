## Diagnose a problem

Start with the selected Project's Night Card, Night Summary, and affected Work Card. The Managed Block names a blocked Card's reason and next action. Make triage decisions in Linear; use Settings for local configuration.

If no Night Card exists, use `yh status --project YOUR_PROJECT_ID` to inspect scheduled jobs, recent runs, sleep history, and missed Nights. Use `yh doctor --project YOUR_PROJECT_ID` to check readiness. Ordinary diagnostics report findings; `doctor --fix` is an explicit repair operation.
