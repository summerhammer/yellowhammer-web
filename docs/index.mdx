Yellowhammer runs unattended engineering [Nights](/reference/statuses-and-glossary#night) on your Mac. It turns your specification into [Features](/reference/statuses-and-glossary#feature) and Work Cards, coordinates coding agents across a [Project](/reference/statuses-and-glossary#project)'s repositories, and opens pull requests for your review.

## How it fits together

Linear holds your Features, Work Cards, questions, and Night Summary. Orca ADE creates the Worktrees where your local agent CLIs work. GitHub holds the resulting pull requests. You make decisions in Linear and choose what to merge in GitHub.

Each Project has its own repositories, specification source, schedule, and limits. A Night can progress through multiple Features as work finishes, subject to those limits. Work Cards for the same repository run in order; different repositories can advance independently.

## Run locally, review when ready

Scheduled jobs run on your Mac even when the Yellowhammer window is closed or the app is quit. Keep the Mac available during the Night window and set up the local tools before leaving it unattended. The [Pulse](/review/understand-pulse-and-inspector) lets you inspect activity and follow links to Linear.

Start with the [setup overview](/setup/overview), then learn how to [run Nights](/run/overview) and [review the morning](/review/overview).
