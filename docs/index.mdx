# Yellowhammer

Yellowhammer is a fast, keyboard-first macOS menu bar application designed to seamlessly bridge your desktop development workflow with issue trackers like [Linear](https://linear.app).

## Architecture

Yellowhammer consists of two main pieces:
- **Mac Application:** Native client for macOS menu bar.
- **Code Relay:** A privacy-first Cloudflare Worker that relays short-lived OAuth authorization codes securely without storing user tokens.
