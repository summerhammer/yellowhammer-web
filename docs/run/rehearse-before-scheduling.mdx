A Rehearsal Night is a deliberate trial used to inspect readiness and execution behavior. Confirm the current prerequisites and reporting surfaces before starting one.

<DocumentationOutline />

## Goal

Use a Rehearsal Night to inspect readiness and reporting before relying on a schedule.

## Before you begin

Review [Requirements](/start/requirements). Confirm the Project has the separate rehearsal board project and Journal required by the product glossary; verify current setup labels and availability in the installed release.

## Steps

### Check rehearsal prerequisites

Identify the rehearsal context that must exist and the product evidence that the action is available. A rehearsal is a mode of a Night, not a separate sandbox environment.

### Start the rehearsal

Document the current user-initiated flow and any warnings that appear. Do not publish a command or button name until verified.

### Review its result

Follow the rehearsal Night Card and Night Summary. Identify setup, routing, or execution issues to resolve before unattended scheduling.

## Confirm it worked

Describe the record that proves a rehearsal ran and where its result appears. State what a successful result does and does not establish.

## Common problems

Cover a missing rehearsal board, missing rehearsal Journal, and a rehearsal result that reports an execution issue. Give verified diagnostic paths.
