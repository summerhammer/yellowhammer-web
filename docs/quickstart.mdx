# Quickstart

Follow these steps to install and configure Yellowhammer on your Mac.

## 1. Download Yellowhammer

Download the latest version of the application:
- [Download for macOS (Apple Silicon & Intel)](https://github.com/summerhammer/yellowhammer/releases/latest/download/Yellowhammer.dmg)

## 2. Installation

1. Open the downloaded `Yellowhammer.dmg` disk image.
2. Drag **Yellowhammer** into your `/Applications` folder.
3. Launch Yellowhammer from `/Applications` or Spotlight (`Cmd + Space`).

## 3. Connect Linear

1. Click the Yellowhammer icon in your macOS menu bar.
2. Select **Connect Issue Tracker** and authenticate with Linear.
3. The browser will relay the authorization code back to your Mac app automatically.
