A Project represents one product and its repositories, Linear project, and specification. A Feature describes a unit selected for a Night; Work Cards represent its pieces of work in Linear.

<DocumentationOutline />

## Definitions

Define Project as product scope, Feature as the unit of intent selected for a Night, and Work Card as one repository-scoped dispatchable unit. Link each first-use term to the glossary.

## How they relate

A Project contains its repositories, Linear project, and specification. One Feature is in flight per Project; it may produce several Work Cards, each tied to one repository.

## What this means for triage

Use the Project to scope the Night, the Feature to understand the intended outcome, and individual Work Cards to inspect execution or answer a request.
