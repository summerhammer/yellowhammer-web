## Where execution happens

Yellowhammer runs on the Mac, allocates Orca worktrees, and invokes the user’s agent CLI. The agent CLI, rather than Yellowhammer itself, writes code.

## What stays on your Mac

Describe code, credentials, and agent subscriptions as local product commitments. Verify which integration reads each credential and avoid promising that external tools never transmit data.

## Permission boundaries

Explain the user’s responsibility to grant only the access needed. Protected Paths are checked before dispatch and do not constrain changes after an agent starts.
