A Definition of Done states what must be true for a Feature to count as complete. Verification reports against its clauses and citations; this makes the judgment auditable, not a guarantee that the work is correct.

<DocumentationOutline />

## Definition of Done

Define this as the set of completion clauses written before code exists. Each clause cites a specific specification location.

## Clause-level evidence

Explain that Verification reports on each clause with its citation and result. The page should show what evidence is carried to the Feature record and pull request after verification is confirmed.

## What verification can tell you

Verification makes the judgment traceable to stated criteria. It does not prove the specification is current or that the implementation is correct.
