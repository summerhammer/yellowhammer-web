A Project needs macOS 26, Orca ADE, Linear, GitHub, and at least one supported agent CLI. The Mac must remain available for unattended execution. Confirm current compatibility details before setup.

<DocumentationOutline />

## Before you begin

Use this page to check readiness, not to infer a supported version from an old setup guide. Verify the current release requirements before connecting services.

## Mac and local environment

Confirm macOS 26 compatibility, available disk space for repositories and worktrees, and that the Mac remains available during the configured Night window. Verify sleep and login requirements in the current scheduler.

## Connected services

Check access to the Linear workspace and project, GitHub repositories that may receive pull requests, and Orca ADE. The current product brief requires workspace administrator access for Linear setup; verify this requirement before publication.

## Agent access

Confirm at least one supported agent CLI is installed for the macOS account that runs Nights. Check current CLI version, authentication, and the model/effort combinations the product can use.
