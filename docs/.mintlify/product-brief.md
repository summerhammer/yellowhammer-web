# Product brief

## Description

Yellowhammer coordinates unattended engineering Nights on an Apple Silicon Mac. It takes work from Linear, runs authenticated coding agent CLIs in Orca ADE Worktrees, and publishes results for human review through Linear and GitHub pull requests.

## Primary audience

Developers and small teams setting up, operating, and reviewing their own Projects. The existing documentation structure establishes this end-user audience; contributor and deployment documentation are outside this content pass.

## Jobs to be done

- Connect Linear, code hosting, Orca ADE, and coding agent CLIs; configure a Project and its repositories.
- Prepare verifiable specification material, check readiness, rehearse, and configure unattended Nights.
- Inspect progress in the Pulse and Inspector, answer questions in Linear, and review resulting pull requests.

## Motivation

Advance a multi-repository product while its operator is away, using existing local tools and agent subscriptions. Keep triage and decisions in Linear, and leave merging to the operator.

## Documentation baseline

Document the current local sibling app source, as selected by the user on 2026-10-27. Use the specification for canonical terminology and verify behavior in implementation. Preserve the six navigation groups and existing URLs. Mark unimplemented sections TBD and leave screenshot capture briefs; do not create screenshots or diagrams.
