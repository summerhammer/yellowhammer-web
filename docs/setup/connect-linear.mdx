## Goal

Prepare the Linear workspace and Project that will carry Night triage.

## Before you begin

The current product brief requires workspace administrator access for Linear setup. Confirm whether this remains true for the installed release, identify the intended workspace and Linear project, and review [Requirements](/start/requirements).

## Steps

### Confirm workspace access

Check that the account can access the intended workspace and perform the setup actions the current release requires. Verify the exact role requirement before publishing instructions.

### Connect the workspace

Document the current connection flow and app installation step only after checking the shipped app. Record which workspace and operator identity the connection represents.

### Select the Project board

Explain how the Linear project scopes a Yellowhammer Project and what to check when several projects or workspaces are available.

## Confirm it worked

Name the visible connection status and the selected workspace/Project evidence. Confirm the app can read the intended Linear project before scheduling a Night.

## Common problems

Cover insufficient workspace permissions, an unavailable workspace, and a connection that exists but points to the wrong Project. For each, identify the diagnostic evidence and verify the supported remedy.
