## Start with the Night Summary

1. Select your Project in the sidebar. In **Tonight / last Night**, open the verdict link to its Night Card in Linear.
2. Read the [Night Summary](/review/read-the-night-summary), starting with its verdict and any failures. A Night can advance work without opening a pull request.
3. Open **Needs you** to inspect Work Cards that are Blocked or Waiting on You. Follow each Card's link to Linear to answer or re-ready it.
4. Review every linked repository pull request in GitHub. Check for a Partial Landing or a notice that it is stacked on an earlier Feature.
5. Revisit **Feature** for the active Feature and the Features awaiting merge. A Night can land several Features sequentially, so review the entire unmerged stack.

## Keep the decision with its record

The Inspector shows the recorded reasons, routes, Attempts, Rounds, and Check results. It does not answer questions or move Cards to Todo. Make those changes on the Linear issue. Merge decisions belong in GitHub.

Yellowhammer reads your changes during later Acts. A returned Feature can remain visible until the next author Act reads the board; it does not disappear immediately when you act.
