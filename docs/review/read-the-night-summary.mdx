The Night Summary records the result of a Night, including work completed and exceptions that need attention. Check its links to the underlying Linear records before deciding what to do.

<DocumentationOutline />

## What the summary tells you

Locate what completed, what stopped, what needs a human decision, and which pull requests were opened. The Night Summary should link back to the records that support each outcome.

## Follow the records

Open the linked Work Card for a blocked item or human question, and the repository pull request for code review. Keep the Linear record as the place to make triage decisions.

## Acme Checkout example

Trace one illustrative checkout outcome from the Feature to its Work Cards, verification result, and repository pull request. Label any invented behavior as an example, not a product promise.
